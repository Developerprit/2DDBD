## 关键技术决策
- **1 tile = 16 世界像素 = 1 米**，于是原作的 m/s 数值可以原样写进代码（逃生者 4.0、杀手 4.6、
  扛人 3.68、后摇 2.76、恐惧半径 32 m、发电机 80 s、大门 20 s、踩板 2.6 s）。
- **美术双输出**：`tools/gen_sprites.py` 同时产出 SVG（矢量源，可编辑）与 PNG（1:1 运行时纹理，
  规避光栅化抗锯齿糊边）。PNG 用 zlib 手工编码，零第三方依赖。
- **音效全合成**：`tools/gen_audio.py` 用振荡器/噪声/包络 + 微型音序器产出 51 个音效、74.8 秒音频。
- **网络层三后端**（`NetOffline` / `NetEnet` / `NetWebRTC`）藏在 `NetBase` 接口后，
  角色逻辑完全不感知传输层；WebRTC 用手动 SDP 文本交换实现无服务器 P2P。
- **地图确定性程序化生成** + `AStarGrid2D` 寻路（比 NavigationRegion 烘焙简单得多，且天然适配瓦片地图）。

## 踩过的坑（已全部修复，详见 skill: godot-4-pixel-game）
信号自递归导致 stack overflow；TileSet 必须先 add_source 再设 TileData 碰撞；
StateMachine 内部类状态名需要显式 register(name, state)；多行 lambda 不能含 if/else；
`_ = x` 在 GDScript 非法；物件碰撞体过大封死通道；隔墙挥刀死循环；
卡住看门狗必须用净位移而非逐帧位移；导出 Windows 需要 .ico + 四段版本号。

## 已知限制
联机层具备大厅/握手/状态同步接口但未经多人实测；AI 能打完整局但板窗博弈水平朴素；
UI 用 Godot 内置字体，像素位图字体在路线图上。

## v1.1 迭代（同日 14:00）

陌老师报 4 项，全部完成并推送（`eefa5f3`），exe 已重新导出。

### ① 翻越彻底失效（真 bug，根因两层）
1. `WindowVault`/`Pallet` 的 `hold_interact()` 都返回 false，交互走通用进度条管线 →
   `on_interact_start()` 播完音效就 `end_interaction()`，**没有任何位移**。
   修法：在交互**分流阶段**就进 `VaultState`，而不是进 `InteractionState`。
2. 修完仍不生效：窗户打在实心墙格上，**A\* 把它当实心** → 所有 bot 绕开窗户，
   翻越代码永不触发。修法：把窗户格标为可走 + 1.8 倍权重。
3. AI 翻越判定第一版用「前方 1.1 格探针点是否靠近障碍」，几乎不触发。
   改成「测真实距离 + 障碍须在行进方向半平面内 + 逃跑时不校验是否更接近目标」。
   **压测验证：120 秒内翻越 11 次（修复前恒为 0）。**

### ② F11 无边框全屏
`SceneRouter._input` 处理全局快捷键，`WINDOW_MODE_FULLSCREEN` + `WINDOW_FLAG_BORDERLESS`，
状态存 `GameConfig.fullscreen`。

### ③ UI 按钮超出窗口
12 个技能按钮横排 ≈1400 px（窗口才 640 逻辑宽）。改为 `HFlowContainer` 自动换行，
所有页面套 `ScrollContainer`（否则矮窗口下底部按钮点不到）。
**踩坑**：`_panel()` 套了 ScrollContainer 后，loadout 页原本的内层 ScrollContainer 要删掉，否则嵌套滚动失效。

### ④ 血网系统
`src/systems/bloodweb.gd`（种子化节点生成 + 经济曲线）+ `src/ui/bloodweb_view.gd`（环状界面）。
`SaveData.bloodweb` 按角色存 `{tier, taken[], unlocked[]}`，**节点图不存**（由 `(char_id, tier)` 确定性重算）。
配装页按解锁状态过滤技能；每角色默认送专属技能 + 2 个基础技能，新档送 24000 BP。

### 新踩的坑
- **新增带 `class_name` 的脚本后，`--check-only` 会报 "Identifier not declared"，必须先跑一次 `--import`**
  让 Godot 扫描注册全局类。这次卡了两轮。
- `Write` 工具可能**静默失败**（无输出且文件未创建）—— 写完后务必 `ls` 确认。
- `Utils.Facing` → 应为 `Enums.Facing`；容器类型改 `HFlowContainer` 时变量声明也要跟着改。

### ③ AI 感知三件套
- 逃生者：红光 = 硬危险信号；逃跑方向取**垂直于光轴**（沿光轴跑会一直待在正面）
- 杀手：新增 `Mode.SCRATCH`，跟 16 m 内最新划痕，并用次新划痕反推方向后**外推 6 格**
  （避免停在最后一个脚印上）
- 优先级：视野中逃生者 > 划痕 > 最后已知位置 > 巡逻
- **压测验证：150 秒内跟随划痕 81 次、翻越 20 次**

### ④ 视线遮挡
- `CanvasModulate` 环境暗度 0.46 + 墙体 TileSet occluder + 角色 `PointLight2D`（开阴影）
- `MatchController._update_occlusion()`：被墙挡住的敌人半透明（0.30），柜子里的完全不可见
- **状态色从 `modulate` 迁到 `self_modulate`**，把 `modulate.a` 让给遮挡 —— 否则眩晕红和遮挡淡出会互相覆盖

### 新坑
- **bash 里 `git commit -m "...`反引号`..."` 会被命令替换**，导致提交信息缺词。含反引号的内容要用 `-F` 或 heredoc。
- Godot 导出时若旧 exe 被占用会报「重命名临时文件失败」，先删 build 目录再导出。
