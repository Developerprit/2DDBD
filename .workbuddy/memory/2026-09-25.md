## 关键技术决策
- **1 tile = 16 世界像素 = 1 米**，于是原作的 m/s 数值可以原样写进代码（逃生者 4.0、杀手 4.6、
  扛人 3.68、后摇 2.76、恐惧半径 32 m、发电机 80 s、大门 20 s、踩板 2.6 s）。
- **美术双输出**：`tools/gen_sprites.py` 同时产出 SVG（矢量源，可编辑）与 PNG（1:1 运行时纹理，
  规避光栅化抗锯齿糊边）。PNG 用 zlib 手工编码，零第三方依赖。
- **音效全合成**：`tools/gen_audio.py` 用振荡器/噪声/包络 + 微型音序器产出 51 个音效、74.8 秒音频。
- **网络层三后端**（`NetOffline` / `NetEnet` / `NetWebRTC`）藏在 `NetBase` 接口后，
  角色逻辑完全不感知传输层；WebRTC 用手动 SDP 文本交换实现无服务器 P2P。
- **地图确定性程序化生成** + `AStarGrid2D` 寻路（比 NavigationRegion 烘焙简单得多，且天然适配瓦片地图）。

## 踩过的坑（已全部修复，详见 skill: godot-4-pixel-game）
信号自递归导致 stack overflow；TileSet 必须先 add_source 再设 TileData 碰撞；
StateMachine 内部类状态名需要显式 register(name, state)；多行 lambda 不能含 if/else；
`_ = x` 在 GDScript 非法；物件碰撞体过大封死通道；隔墙挥刀死循环；
卡住看门狗必须用净位移而非逐帧位移；导出 Windows 需要 .ico + 四段版本号。

## 已知限制

UI 用 Godot 内置字体，像素位图字体在路线图上。

### ① 翻越彻底失效（真 bug，根因两层）
1. `WindowVault`/`Pallet` 的 `hold_interact()` 都返回 false，交互走通用进度条管线 →
   `on_interact_start()` 播完音效就 `end_interaction()`，**没有任何位移**。
   修法：在交互**分流阶段**就进 `VaultState`，而不是进 `InteractionState`。
2. 修完仍不生效：窗户打在实心墙格上，**A\* 把它当实心** → 所有 bot 绕开窗户，
   翻越代码永不触发。修法：把窗户格标为可走 + 1.8 倍权重。
3. AI 翻越判定第一版用「前方 1.1 格探针点是否靠近障碍」，几乎不触发。
   改成「测真实距离 + 障碍须在行进方向半平面内 + 逃跑时不校验是否更接近目标」。
   **压测验证：120 秒内翻越 11 次（修复前恒为 0）。**

### ② F11 无边框全屏

**踩坑**：`_panel()` 套了 ScrollContainer 后，loadout 页原本的内层 ScrollContainer 要删掉，否则嵌套滚动失效。

### 根因与重做
旧实现 = 空地上撒随机墙面，**没有任何结构**。重做为「结构优先」：
1. 80×80 划成 5×5 个 16×16 地块，每块分配蓝图（主建筑/建筑/户外体操区/小屋/掩体场）
   —— 旧代码只允许中心 3×3 放建筑，实际最多 4 栋，这是开放率降不下来的直接原因
2. 蓝图建造：外墙 + 按需开门洞 + **内部环廊** + 内室柱子；窗只打在外墙且**两侧确认可走**
3. 户外掩体全部**正交排布**（栅栏段/L 角/平行双墙/中间留缺口的栅栏）
4. 发电机贴建筑 3 格、钩子先保证「每台发电机 13 格内必有一个」
5. **地面纹理改成值噪声分片**（FastNoiseLite 低频 + pow 偏置）；逐格随机会变成电视雪花
6. maps.json 加 layout 字段（每图独立配方）+ **种子混入 map_id**（否则五张图布局完全相同）

### 修掉两个方向性 bug
- 窗的 dir 给的是墙走向的反 90°，落点沿墙而不是穿墙
- 板拿到的是通行方向而不是板面走向 → 板旋转 90°、沿走廊躺着
- **统一约定：dir/direction 永远表示障碍物的延伸轴，穿越方向取垂直**

### 渲染层（看完截图才发现）
- **画面暗到看不清地形**（环境暗度 0.46 乘算），调到 0.64，角色光 1.7 → 2.6
- **墙是横向条纹**：每块墙瓦片自带上下高光，多格墙就重复成条带。
  改成每材质三种竖向变体（顶边受光/中段纯色/底边阴影），按上下邻居选。

### 新踩的坑（已入 skill）
- **`--write-movie` 可以截图验证真实渲染**（headless 不行）：
  `Godot --path <proj> --write-movie out.png --fixed-fps 10 --quit-after 40 res://scenes/match.tscn`
  → 输出 PNG 序列。**这是发现「太暗」的唯一途径**，逻辑 dump 永远看不到。
- `--check-only` 单文件检查会误报 `Identifier not found: EventBus`（autoload 未加载），**不是真错误**。
- 补丁脚本里**别把 GDScript 语法写进 Python 文件**（这次把 `var x := y` 写进了 .py，直接 SyntaxError）。
- **工具会「重放」命令**：patch 脚本报 MISS 但实际已写入；git commit 报 nothing to commit 但实际已提交。
  **验证要直接查文件/git log，不要相信工具输出的成功/失败**。
- bash heredoc 内容过长/含反引号会炸，**补丁一律写成 .py 文件再执行**。

## v1.6 迭代（同日 15:20）—— 手感、挂钩、字体

陌老师报 6 项，全部完成。提交 `abb0e98` / `e2fec1b`，exe 已重新导出（97.9 MB）。

### ① 红光 3 米
`RED_STAIN_RANGE` 176px（11 米）→ 48px（3 米），角度 54° → 64°。
11 米时红光会照亮小半个屏幕，**反而读不出"他在朝哪看"** —— 而这个光斑唯一的职责就是表达朝向。
顺带把 AI 的"侧向脱离"触发条件补上"被杀手的视线锥罩住（10 米内）"，
否则红光缩短后这条逻辑几乎不再触发。

### ② 挂钩系统大修（根因：**两份状态**）
旧实现里 `Hook.stage`（occupy 设为 FIRST 后再也不动）与 `Survivor.hook_stage`（由 `tick_hook` 驱动）并存，
导致三个硬伤：
- **STRUGGLE 阶段从钩子这侧永远到不了** → 钩子自己无法献祭任何人；
- 阶段判定是 `hook_count == 1 ? FIRST : STRUGGLE` → **第三次挂钩只是又开一次挣扎**，不会立即献祭；
- AI 挣扎值被 `maxf(struggle, 0.25 + ...)` **永久托底** → **挂在钩上的 bot 是不死的**，
  整个献祭循环是装饰品。

重构：阶段 / 计时器 / 挣扎条**全部归钩子所有**，逃生者只镜像。
```
第一次 → FIRST    60 秒救援窗口 + 一次 4% 自救（失败即作废，不可反复掷骰）
第二次 → STRUGGLE 直接挣扎，每秒 -1/60，按住交互键 +0.019/秒
第三次 → 立即献祭，无计时器
同一人挂回同一钩子 → 额外推进一个阶段
```
AI 不提供挣扎输入且每秒 50% 概率失误扣 0.01 → **约 46 秒被献祭**（短到挂钩真有威胁，长到队友来得及救）。
废弃 `Hook.used`（用一次就永久退休 → 长时间对局会**没钩子可用**），改 `last_victim`。

### ③ 板/窗图标重画
木板 = 五条板（受光顶边 + 阴影底边）+ 三条铆钉钢带 + 深色描边；
破损板 = 断板 + 撕裂钢带 + 木屑；窗户 = 石砌窗框 + 窗台 + 两块玻璃 + 斜向高光 + 裂纹。
16×16 UI 图标同步重画（原本木板图标和窗户图标几乎分不出来）。

### ④ 杀手本能指针
`KillerInstinct`（HUD 内的 Control，`_draw` 绘制）：屏幕边缘箭头指向
「被挂钩的逃生者 > 已开地窖 > 通电大门 > 有进度的发电机」，附距离（米）；屏幕内改画菱形。
**只有杀手可见** —— 逃生者的核心体验就是"不知道"。

### ⑤ AI 不会脱手（根因：**决策层与状态机脱节**）
`_decide()` 把 `goal_kind` 改成 `flee`，但状态机还停在 `interact`，
而 **`InteractState` 根本不读 `move_input`** → 杀手贴脸了 bot 还在专心修机。
修法：所有目标变更统一走 `_set_goal()`，它在目标真变化时先 `_release_interaction()` 再改目标。
**"改主意"必须落到状态机上，光改意愿没用。**

### ⑥ 像素位图字体
`tools/gen_font.py`：95 个**手写** 5×7 点阵字形 → AngelCode BMFont（`.fnt` + PNG），
Godot 原生导入为 `FontFile`。手写而非从系统 TTF 二值化（抗锯齿栅格化后形状发虚、依赖字体）。
中文回退用 `SystemFont`（雅黑/黑体/Noto CJK…）。

### 本轮新踩的坑（已入 skill）
- **BMFont 的 `fallbacks` 会替换引擎隐式回退链**：指向 `ThemeDB.fallback_font` 时中文全部变豆腐块，
  必须显式给 `SystemFont` 并列出 CJK 字体名。
- **Godot 4 移除了 `Camera2D.unproject_position()`**（Godot 3 API）。世界→屏幕要改用
  `get_viewport().get_canvas_transform() * world_pos`。
- **`Interactable` 基类已有 `occupant: Node`**：子类不能再声明同名成员（Parse Error），
  而且基类是弱类型 `Node`，直接调自定义方法会失败，必须用自己强类型字段。
- 工具重放**会让同一个 commit 提交两次**：`git reset --soft HEAD~1 && git commit --amend --no-edit` 可合并。
